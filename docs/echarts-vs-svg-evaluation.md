# ECharts versus SVG

## Decision scope

This is a comparison of the experimental ECharts lab against the stable SVG
dashboard. It is not an authorization to replace the stable implementation.

| Criterion | Stable SVG | ECharts lab | Current assessment |
|---|---|---|---|
| Static GitHub Pages | Works | Works with local bundle | Tie |
| External runtime dependency | None | None after local bundling | Tie |
| Historical comparison | One stable view | Two entities and six series | ECharts advantage |
| Data transformation | Application code | ECharts dataset transforms | ECharts advantage for experimentation |
| Accessibility | Native labels and stable DOM | ARIA generated by ECharts plus native controls | Requires manual review |
| Responsive behavior | Covered by stable dashboard QA | Covered by seven E2E scenarios and desktop/mobile visual review | Tie |
| Bundle cost | No chart engine bundle | Local ECharts bundle under 1.5 MB transferred | SVG advantage |
| Interaction potential | Intentionally limited | Tooltip, legend scroll and data zoom | ECharts advantage |
| Maintenance risk | Low and known | New dependency and option contracts | SVG advantage |
| Production readiness | Existing baseline | Experimental branch only | SVG remains default |

## Evidence available

- ECharts browser scenarios: `7 passed`.
- Python contracts: `29 passed`.
- Local bundle: no CDN request detected.
- Local bundle: below the `1.5 MB` transfer threshold.
- Visual review: desktop and mobile screenshots captured with no horizontal
  overflow in the stable dashboard or ECharts lab.
- Stable dashboard: unchanged by this experiment.

## Decision

Promote ECharts for the Project 02 demonstration branch only. Its two-entity
comparison, six-series view, tooltip, legend scroll and data zoom provide
material value for the agreed middle-level analyst scope. Keep the stable SVG
dashboard as the default renderer and fallback until a separate integration
change proves that the larger bundle and maintenance cost are justified for
the shared production surface.

This decision is reversible: the Project 02 branch can continue with ECharts
without changing `main`, and the stable SVG implementation remains available
for rollback.

## Remaining gates

1. Integrate the approved ECharts view into the Project 02 presentation path,
   not into the stable SVG dashboard.
2. Add the final data quality, label, accent and ranking checks.
3. Rerun all stable QA, smoke and Pages checks after integration.
